# Bot commands

Commands are case-insensitive. In groups, the bot usually responds to commands and when mentioned or replied to; the owner must enable a group with `/enablegroup`.

## OriginOS & customization

`/island` · `/islandmusic` · `/originplayer` · `/originos` · `/latest` · `/funtouch` · `/region` · `/aod` · `/notifications` · `/background`

## Devices & updates

`/lookup vivo V30` · `/lookup iQOO 12` · `/updates` · `/beta` · `/iqoo` · `/flashcharge` · `/battery`

## Tips & troubleshooting

`/games` · `/camera` · `/gcam` · `/storage` · `/ram` · `/debloat` · `/apk` · `/bugs` · `/ask` · `/support` · `/rules`

## AI & privacy

`/about` · `/usage` · `/privacy` · `/forget` · `/memory on|off` · `/language auto|en|ms|hi|id|zh|ta|ar`

## Utilities

`/banner` · `/polls`

## Admin / owner-only

`/admin` lists available commands, including `/settings`, `/set`, `/enablegroup`, `/disablegroup`, `/chatid`, `/warn`, `/unwarn`, `/ban`, `/unban`, `/info`, `/reset`, `/clear`, `/setbanner`, and `/poll`.

## BotFather command list

Paste the following text into BotFather after `/setcommands`. **No slash** before command names; parameters are supplied separately when a user invokes the command.

```text
start - Start vivo Assist AI
help - View all available commands
island - Set up Origin Island
islandmusic - Fix unsupported music players
originplayer - OriginOS music controls
originos - OriginOS features and customization
latest - Check the latest OriginOS version
funtouch - Funtouch OS information
region - China ROM vs Global ROM
aod - Always On Display guide
notifications - Fix notification issues
background - Fix background app restrictions
lookup - Search vivo and iQOO phone models
updates - Software updates and OTA rollout
beta - Beta updates and early access
iqoo - iQOO device information
flashcharge - vivo FlashCharge guide
battery - Battery health and optimization
games - Gaming performance and FPS
camera - Camera features and tips
gcam - Google Camera compatibility
storage - Storage management and cleanup
ram - Extended RAM and memory management
debloat - Remove unwanted apps safely
apk - Fix APK installation problems
bugs - Report bugs and software issues
ask - How to ask for technical help
support - Official vivo support resources
rules - Community rules and guidelines
about - About vivo Assist AI
usage - Check daily AI and search usage
privacy - Privacy and data handling
forget - Clear saved conversation memory
memory - Enable or disable AI memory
language - Change AI response language
banner - Display the community banner
polls - Information about community polls
```
